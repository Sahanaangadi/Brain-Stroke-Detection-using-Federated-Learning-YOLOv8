<h1 align="center">Brain Stroke Detection using Federated Learning & YOLOv8</h1>
<h3 align="center">AI-Based Medical Detection System with Privacy-Preserving Learning</h3>

---

## Project Overview
This project focuses on detecting **brain stroke regions from medical images** using **YOLOv8** and **Federated Learning**.

- **YOLOv8** is used for real-time object detection  
- **Federated Learning** ensures data privacy by training models locally without sharing raw data  

---

## Key Features
- Real-time stroke detection using deep learning  
- Privacy-preserving training using federated learning  
- Multi-client training simulation  
- Model evaluation and accuracy tracking  

---

## Tech Stack
- **Language:** Python  
- **Frameworks:** YOLOv8 (Ultralytics)  
- **Concepts:** Federated Learning, Deep Learning  
- **Libraries:** NumPy, OpenCV, PyTorch  
- **Tools:** Jupyter Notebook / VS Code
